Namespaces

Pick a cluster, then a namespace. See what Git holds beside what the cluster has, and change its labels and annotations. Changes go through a request, approval and Git, like a new namespace.

Adopt an existing namespace

A namespace that cmapi does not manage is adopted only when it carries the label cmapi.net/adopt: "true". cmapi reads it as it is, writes it to Git under the custom tier, and lists every difference from the rules as a finding. A person approves it, and the change reaches the cluster only through a pull request.
