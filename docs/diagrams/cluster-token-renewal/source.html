How cmapi renews each cluster's import token

Each managed cluster is reached with a bounded TokenRequest token for cmapi-system/cmapi-reader, kept in an import Secret on the hub. The worker renews it before it expires, so nobody renews tokens by hand. The manual script stays as the fallback. Shipped in #469 and #478, and proven on CRC on 2026-11-20.
