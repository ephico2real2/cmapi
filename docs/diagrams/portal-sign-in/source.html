The portal: from sign-in to a permitted call

OpenID Connect Authorization Code with PKCE, through the public client cmapi-portal. The portal keeps its tokens in memory and takes each permission from GET /api/v1/me.

Each step is built in cmapi-portal-ui and tested against a stand-in issuer and a stand-in API (tests/api). No step was measured on a real Keycloak or on CRC.
