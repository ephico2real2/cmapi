The front door: one origin for the portal and the API

nginx in the cmapi-portal image serves the portal and sends the API's paths to the API pods, so the browser needs no CORS.

Built in the chart and tested on this Mac with nginx 1.30.6 and Chromium (deploy/tests/front-door-test.py, cmapi-portal-ui/tests/front-door.test.mjs). Not measured on a cluster (#157). The host names are CRC's.
